# Unit 3 — MongoDB Aggregation Pipeline

**MCA Assignment**

E-commerce dataset aggregations using MongoDB pipeline operators (`$match`, `$project`, `$group`, `$unwind`, `$lookup`, `$facet`, etc.).

## Database

- **Name:** `ecommerce_practice`
- **Collections:** `customers`, `products`, `orders`, `payments`

## How to run

1. Open **MongoDB Compass** → database `ecommerce_practice`.
2. Select the collection for that question.
3. **Aggregations** → **TEXT** mode.
4. Paste only the `[ ... ]` array from the questions file.
5. Click **Run**.
